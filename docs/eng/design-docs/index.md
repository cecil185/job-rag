## How to add one

1. New file: `docs/eng/design-docs/NNN-short-slug.md` (NNN = next number).
2. Sections: **Context**, **Decision**, **Consequences**, **Alternatives considered**.
3. Add a one-line entry to the index above with a link.
4. Keep it short. If it's longer than two screens, you're probably mixing decisions.
